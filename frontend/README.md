# Web app

React + TypeScript + Vite, styled with [shadcn/ui](https://ui.shadcn.com) (Tailwind v4, Radix),
charts from shadcn's chart components (Recharts), animation with [Motion](https://motion.dev).

The app only displays results; every decision comes from the FastAPI service.

```bash
npm ci
npm run dev      # http://localhost:5173/ui/ , proxies API calls to a service on :8000
npm run build    # writes the production build to ../service/web (commit it)
```

`service/web` is committed so teammates can run the service without Node. After changing
anything here, run `npm run build` and commit both `frontend/` and `service/web/`.

Layout: `src/App.tsx` (state and data flow), `src/components/*` (panels and charts),
`src/components/ui/*` (generated by the shadcn CLI), `src/lib/api.ts` (typed API client),
`src/lib/domain.ts` (labels, presets, tier colours).
